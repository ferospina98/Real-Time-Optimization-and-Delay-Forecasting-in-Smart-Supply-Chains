# Real-Time-Optimization-and-Delay-Forecasting-in-Smart-Supply-Chains
This project uses smart logistics sensor data to analyze supply chain performance, detect key drivers of delays, and build a predictive model to help logistics teams act proactively.

Objectives
1. Geospatial Analysis – Visualize asset routes and identify clusters of shipment delays using coordinate data.
2. Exploratory Data Analysis (EDA) – Understand relationships between traffic status, asset utilization, demand forecasts, and delay rates.
3. Predictive Modeling – Build a machine learning classifier to predict the probability of logistics delays.
4. Optimization Insight – Provide operational recommendations based on model results and observed trends.

⸻

Tools & Libraries
- Python (pandas, seaborn, matplotlib, folium, scikit-learn)
- Machine Learning: Random Forest Classifier
- Geospatial Mapping: Folium
- EDA & Visualizations: seaborn, matplotlib, plotly

⸻

Key Outcomes
- Achieved ~74% OOB accuracy in predicting logistics delays
- Identified traffic status as the most critical factor contributing to delays
- Delivered actionable insights on routing, asset management, and demand balancing
